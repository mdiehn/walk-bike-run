# v0.2.0 stabilization

v0.2.0 is the local/manual route planner milestone.

## Included scope

- manual route point editing
- route list editing
- draggable route markers
- route distance and simple time estimates
- local saved route library
- saved route sort/filter controls
- current-route JSON and GPX import/export
- saved-library JSON backup/restore
- unsaved-change guards
- clearer saved-route selection vs current-route behavior

## Before release

Run the normal checks:

```sh
npm run lint
npm test
npm run build
npm run test:e2e
```

Then do a quick browser pass:

- create a route on desktop
- save it
- load it
- edit it and save changes
- save as new
- select another library row without loading it
- export/import current route JSON
- export/import current route GPX
- export/import library backup JSON
- confirm unsaved-change prompts appear before destructive actions

Then do a short mobile pass over LAN:

- load the dev server Network URL
- add a few route points
- drag a marker
- scroll the route/library panels
- save and load a route
- check that buttons are reachable

## Not release blockers

These are planned for later and should not block v0.2.0:

- road/path routing
- GPS recording
- installable PWA behavior
- offline caching
- custom pace profiles
- polished mobile layout
- choose-destination/share flow for exports
